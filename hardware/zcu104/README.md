# ============================================================================
# ZCU104 Hardware Integration - UHTC Aperiodic Cooling Engine
# ============================================================================
#
# This directory contains the ZCU104 FPGA hardware assets imported from the
# official Xilinx PYNQ repository and organized for the UHTC project.
#
# Sources:
#   - Xilinx/PYNQ (boards/ZCU104)
#   - UG1267 - ZCU104 Evaluation Board User Guide
#   - UG961  - AXI4-Stream Protocol Reference
#   - UG1037 - AXI4-Lite Protocol Reference
#
# Directory layout:
#   hardware/zcu104/
#   ├── constraints/            Xilinx Design Constraints (XDC)
#   ├── hls/                    HLS kernel source templates for UHTC
#   ├── drivers/                Host-side driver templates
#   ├── tcl/                    Vivado TCL build scripts
#   ├── ip/                     Packaged IP cores
#   ├── block_design/           Vivado block design exports
#   ├── testbenches/            VHDL AXI transaction-level models
#   └── docs/                   Additional hardware documentation
#
# ============================================================================
# Quick Start
# ============================================================================
#
# 1. Build ZCU104 base overlay (requires Vivado 2024.1+):
#
#       cd hardware/zcu104/tcl
#       vivado -mode batch -source base.tcl -notrace
#       vivado -mode batch -source build_bitstream.tcl -notrace
#
# 2. Run VHDL testbenches (requires GHDL or Vivado xsim):
#
#       cd hardware/zcu104/testbenches
#       make ghdl_compile && make ghdl_run && make ghdl_view
#
#    Or with Vivado xsim:
#
#       make xsim_compile && make xsim_run
#
# 3. Program ZCU104 with the generated bitstream:
#
#       xsct/program_hw.tcl hardware/zcu104/base.bit
#
# ============================================================================
# ZCU104 Board Reference
# ============================================================================
#
# Part:   XCZU7EV-2FFVC1156I
# OS:     PYNQ image v2.4 (Ubuntu 20.04 based)
# Kernel: 5.10.0-1035-oem
# Python: 3.8
#
# Key interfaces used by UHTC:
#   - AXI4-Lite @ 0x80000000  (PS -> PL register control)
#   - AXI4-Stream             (PS -> PL laser commands)
#   - AXI4-Stream             (PL -> PS thermal feedback)
#   - /dev/uio0               (UIO mmap for low-latency AXI Lite)
#   - PMOD GPIO               (optional galvo mirror control)
#
# Boot dip switches (SW6):
#   Mode 0: ON, Mode 1-3: OFF  (boot from Micro-SD)
#
# ============================================================================
# Register Map (AXI Lite @ 0x80000000)
# ============================================================================
#
# Offset  | Register           | Access | Description
# --------|--------------------|--------|-------------------------------
# 0x00    | LASER_POWER_REG    | RW     | [15:0] power_W (0-2000 W)
# 0x04    | GALVO_X_REG        | RW     | [15:0] galvo_x DAC count
# 0x08    | GALVO_Y_REG        | RW     | [15:0] galvo_y DAC count
# 0x0C    | MOD_FREQ_REG       | RW     | [15:0] mod_freq, [15:0] mod_phase
# 0x10    | STATUS_REG         | RO     | [0] emergency_stop, [1] thermal_runaway
# 0x14    | TEMPERATURE_REG    | RO     | [31:0] temperature_K (float32)
# 0x18    | DT_DT_REG          | RO     | [31:0] dT_dt (float32)
# 0x1C    | TIMESTAMP_REG      | RO     | [31:0] timestamp_ms
# 0x20    | COMMAND_COUNT_REG  | RO     | [31:0] n_commands_queued
# 0x40    | STREAM_TRIG_REG    | WO     | write any value to assert stream ready
#

# ============================================================================
# TCL Scripts Reference
# ============================================================================
#
# base.tcl
#   Generated by Vivado IP Integrator (2024.1).  Recreates the ZCU104 base
#   block design including Zynq UltraScale+ PS, AXI Interconnect, HDMI,
#   and video pipeline.
#
# build_bitstream.tcl
#   Wraps base.tcl, adds constraints, implements, and writes bitstream.
#   Outputs: base.bit, base.hwh, base.xsa
#
# build_ip.tcl
#   Rebuilds HLS IP cores from source.  Used by makefile_us_alveo.mk.
#
# check_timing.tcl
#   Verifies all user timing constraints are met after implementation.
#
# ============================================================================
# AXI4-Lite Timing (from base.xdc)
# ============================================================================
#
# The ZCU104 base.xdc defines pin constraints for:
#   - HDMI RX/TX (differential pairs)
#   - PMOD GPIO (LVCMOS33, 16 pins each)
#   - I2C (fmch_iic_scl_io, fmch_iic_sda_io)
#   - System reset (M11, LVCMOS33)
#
# For UHTC custom overlay, add to your XDC:
#   set_property PACKAGE_PIN <pin> [get_ports {your_signal}]
#   set_property IOSTANDARD LVCMOS33 [get_ports {your_signal}]
#
# ============================================================================
# Troubleshooting
# ============================================================================
#
# Problem: Vivado reports "Timing constraints are not met"
# Solution: Run check_timing.tcl after implementation.  If failures persist,
#           relax clock constraints in base.tcl or optimize HLS kernels.
#
# Problem: /dev/uio0 not found on ZCU104 Linux
# Solution: Ensure UIO driver is loaded:
#           $ echo uio_pdrv_genirq.of_id=generic-uio > /sys/module/kernel/parameters/modprobe
#           Or add to /boot/extlinux/extlinux.conf: uio_pdrv_genirq.of_id=generic-uio
#
# Problem: Python script cannot find overlay
# Solution: Verify bitstream path and permissions:
#           $ ls -la /home/xilinj/uhc_laser.bit
#           $ sudo xbutil program -p uhc_laser.bit
#
